# Third-party notices

## Runtime dependencies

Symbolic-U depends on third-party Python packages that are **not vendored** into
this repository:

- NumPy
- Pillow
- OpenCV Python bindings (`opencv-python-headless`)

Those projects retain their own licenses. Installing this repository through
`pip` installs them from their normal package sources.

## Grimm source texts

`research/language/grimm_frau_holle.txt` and
`research/language/grimm_der_suesse_brei.txt` contain historical Grimm fairy-tale
text used as research material. The underlying literary works are public domain.
The project does not claim authorship over those texts.

## Related-work references

Bibliographic references and links in `docs/PRIOR_ART.md` point to third-party
research. No third-party paper text is bundled in the repository.
