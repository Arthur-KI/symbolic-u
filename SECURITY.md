# Security policy

Symbolic-U is a research prototype and is **not intended for safety-critical or
security-critical deployment**. In particular, the robotics discussion and sensor
experiments are not a safety certification.

For code-security issues, open a private GitHub security advisory if the repository
has that feature enabled. For ordinary research bugs, use a normal issue.

Do not report a model giving `UNKNOWN` as a security vulnerability by itself; in
this architecture, abstention is often intentional.
