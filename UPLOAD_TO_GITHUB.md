# Upload to GitHub

This repository is prepared for `https://github.com/Arthur-KI/symbolic-u`.

**Web upload:** create an empty repository named `symbolic-u`, extract the release
ZIP, then upload the **contents** of the `Arthur-KI-symbolic-u` folder. Do not
upload the ZIP itself expecting GitHub to unpack it.

Full instructions: [docs/GITHUB_UPLOAD.md](docs/GITHUB_UPLOAD.md).
