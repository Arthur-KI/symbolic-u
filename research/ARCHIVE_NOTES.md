# Archive notes

The public package contains the **complete recovered research workspace available
at packaging time**, not a claim that every temporary scratch cell ever created
in the interactive development history was preserved.

## Preservation layers

- `archive_full/flat/` preserves 372 recovered top-level historical
  `symbolic*`/K24 Python, CSV and JSON artifacts with original filenames.
- The curated subdirectories contain the milestone files most useful for direct
  reproduction and reading.
- K24 original visual-curriculum source was recovered in
  `vision/K24_ORIGINAL/`.
- K24c's machine-readable report/checks/curriculum/sensor facts were recovered,
  but no separate original K24c Python driver existed in the recovered workspace.
  `vision/k24c_reproduce.py` is therefore a reproduction harness using the clean
  current modules; it is explicitly not presented as the lost historical source.

Historical files are evidence. Do not silently rewrite them to make old
experiments cleaner or more successful.
