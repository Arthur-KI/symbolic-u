# Current model status

The clean runtime is a controlled non-neural symbolic research prototype. The
integrated suite contains 15 regression tests. K25 multi-sensor selection is a
partial result: it lowers false commitments and sensor cost but leaves many hard
held-out cases `UNKNOWN`.

See [docs/EXPERIMENTS.md](docs/EXPERIMENTS.md) and
[docs/LIMITATIONS.md](docs/LIMITATIONS.md).
